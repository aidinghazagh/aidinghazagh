کامپیوتر دوست دارم.

توسعه‌دهندهٔ نرم‌افزار در آلتن لجستیک، گرگان. بیشتر روزها لاراول و MySQL، و هر وقت کار لازم داشته باشد .NET، فلاتر و کاتلین. امسال کارشناسی ارشد مهندسی نرم‌افزار را شروع می‌کنم.

۱ SHM Shop Managerمدیریت موجودی و فروش برای مغازه‌های کوچک API لاراول · فلاتر M +

کالا، مشتری، سفارش و پرداخت‌های جزئی، به‌صورت یک اپ فلاتر روی یک REST API لاراولی. هر دو طرف را خودم نوشتم.

  • هر ردیف سفارش، نام کالا، قیمت فروش و قیمت خرید را در لحظهٔ فروش ذخیره می‌کند؛ پس با تغییر قیمت‌ها، سفارش‌های قبلی و محاسبهٔ سود تغییر نمی‌کند.
  • سفارش، اقلامش و اولین پرداخت در یک تراکنش ذخیره می‌شوند. وقتی پرداختی ثبت شد، سفارش قفل می‌شود.
  • هر تغییر قیمت و موجودی ثبت می‌شود، پس هر کالا تاریخچهٔ خودش را دارد.
  • دسترسی بر اساس اشتراک هر فروشگاه کنترل می‌شود و پیام‌های خطای API بسته به زبان فروشگاه، فارسی یا انگلیسی برمی‌گردند.

کد API کد اپ

۲ EXF دیتاست حرکات ورزشی، به فارسی۱٬۳۲۴ حرکت ورزشی ترجمه‌شده به فارسی پایتون · ترجمه با LLM S +

یک دیتاست باز از حرکات ورزشی با انیمیشن، عضلهٔ هدف و تجهیزات، که به فارسی ترجمه‌اش کردم تا اپ‌های ورزشی فارسی دادهٔ واقعی برای شروع داشته باشند. این پروژه فورکی از hasaneyldrm/exercises-dataset است؛ بخش فارسی کار من است.

  • برای هر حرکت، نام فارسی، توضیح کامل و دستورالعمل گام‌به‌گام ترجمه شد.
  • یک اسکریپت پایتون حرکت‌ها را در دسته‌های پنج‌تایی به LLM می‌فرستد، بعد از هر خطا بیشتر صبر می‌کند و پس از هر دسته پیشرفت را ذخیره می‌کند. قطع شدن اینترنت فقط یک دسته را هدر می‌دهد، نه کل اجرا را.
  • پیش از اجرای کامل، چند مدل را از نظر سرعت و کیفیت ترجمه مقایسه کردم.

مشاهده کد

۳ CSC CommitScopeهر پروفایل گیت‌هاب به‌صورت یک خط زمانی React · TypeScript S +

یک نام کاربری گیت‌هاب وارد کنید و خط زمانی مشارکت‌ها، نقشهٔ حرارتی، زبان‌ها و فهرست قابل جست‌وجوی مخزن‌ها را ببینید.

  • بدون ورود هم کار می‌کند و از REST و Events API عمومی گیت‌هاب استفاده می‌کند (حدود ۹۰ روز اخیر).
  • با توکن دسترسی شخصی، برای کل تاریخچه به GraphQL سوییچ می‌کند. گیت‌هاب این کوئری را به یک سال محدود کرده، پس سال‌به‌سال درخواست می‌دهد و نتایج را کنار هم می‌گذارد. توکن هیچ‌وقت از مرورگر شما خارج نمی‌شود.
  • پاسخ‌ها یک ساعت در localStorage نگه داشته می‌شوند تا بازدیدهای بعدی سهمیهٔ API را مصرف نکنند.
