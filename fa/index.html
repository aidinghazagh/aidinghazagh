نمونه‌کارها

Shop Manager

۱۴۰۳ · API لاراول · اپ فلاتر · MySQL

مدیریت موجودی و فروش برای مغازه‌های کوچک — کالا، مشتری، سفارش و پرداخت‌های جزئی — به‌صورت یک اپ فلاتر روی یک REST API لاراولی. هر دو طرف را خودم نوشتم.

  • هر ردیف سفارش، نام کالا، قیمت فروش و قیمت خرید را در لحظهٔ فروش ذخیره می‌کند؛ پس با تغییر قیمت‌ها، سفارش‌های قبلی و محاسبهٔ سود به‌هم نمی‌ریزد.
  • سفارش، اقلامش و اولین پرداخت در یک تراکنش ثبت می‌شوند؛ و وقتی پرداختی ثبت شد، سفارش قفل می‌شود.
  • هر تغییر قیمت و موجودی ثبت می‌شود، پس هر کالا تاریخچهٔ خودش را دارد.
  • دسترسی بر اساس اشتراک هر فروشگاه کنترل می‌شود و پیام‌های خطای API بسته به زبان فروشگاه، فارسی یا انگلیسی برمی‌گردند.

دیتاست حرکات ورزشی، به فارسی

۱۴۰۵ · پایتون · ترجمه با LLM · JSON

یک دیتاست باز از ۱٬۳۲۴ حرکت ورزشی — با انیمیشن، عضلهٔ هدف و تجهیزات — که به فارسی ترجمه‌اش کردم تا اپ‌های ورزشی فارسی دادهٔ واقعی برای شروع داشته باشند. این پروژه فورکی از hasaneyldrm/exercises-dataset است؛ لایهٔ فارسی کار من است.

  • برای هر حرکت، نام فارسی، توضیح کامل و دستورالعمل گام‌به‌گام ترجمه شد.
  • یک اسکریپت پایتون حرکت‌ها را در دسته‌های پنج‌تایی با یک پرامپت سخت‌گیرانهٔ «فقط JSON» به LLM می‌فرستد، بعد از هر خطا بیشتر صبر می‌کند و پس از هر دسته پیشرفت را ذخیره می‌کند — قطع شدن اینترنت فقط یک دسته را هدر می‌دهد، نه کل اجرا را.
  • پیش از اجرای کامل، چند مدل را از نظر سرعت و کیفیت ترجمه مقایسه کردم.
  • مرورگر داخل مخزن، کل کتابخانه را به فارسی و راست‌به‌چپ نشان می‌دهد.

CommitScope

۱۴۰۵ · React · TypeScript · GitHub REST و GraphQL

نام کاربری هر کسی را در گیت‌هاب وارد کنید تا داستانش را ببینید: نمودار مشارکت‌ها در طول زمان، نقشهٔ حرارتی، زبان‌ها و فهرست قابل جست‌وجوی مخزن‌ها.

  • بدون ورود هم کار می‌کند و از REST و Events API عمومی استفاده می‌کند (حدود ۹۰ روز اخیر).
  • با وارد کردن توکن دسترسی شخصی، برای کل تاریخچه به GraphQL سوییچ می‌کند. گیت‌هاب هر کوئری مشارکت را به یک سال محدود کرده، پس سال‌به‌سال درخواست می‌دهد و نتایج را کنار هم می‌گذارد. توکن هیچ‌وقت از مرورگر شما خارج نمی‌شود.
  • پاسخ‌ها یک ساعت در localStorage کش می‌شوند تا بازدیدهای بعدی سهمیهٔ API را هدر ندهند.

درباره

مهندسی کامپیوتر را در گرگان خواندم و از ۱۴۰۲ برای آلتن لجستیک نرم‌افزار می‌نویسم. کاری را دوست دارم که وارد روزمرهٔ آدم‌ها شود — یک صفحهٔ ثبت سفارش، یک فرم، گزارشی که دیگر لازم نیست دستی تهیه شود.

جدا از ساختن اپلیکیشن، به تحلیل داده و امنیت علاقه دارم؛ دوره‌های CS50 در R و SQL، پکیج pingeR و دورهٔ CEH از همین علاقه آمده‌اند.

بیرون از پشت کامپیوتر: کوه‌پیمایی، سفر، دویدن، آواز و گیتار، بازی‌های ویدیویی، سیم‌ریسینگ و شطرنج — در chess.com با من بازی کنید.
