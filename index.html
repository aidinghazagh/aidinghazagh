Selected work

Shop Manager

2024–25 · Laravel API · Flutter app · MySQL

Inventory and sales for small shops — products, customers, orders and partial payments — as a Flutter app on top of a Laravel REST API. I wrote both ends.

  • Each order line stores the product’s name, sale price and purchase price at the moment of sale, so old orders and profit figures don’t shift when prices change.
  • An order, its lines and its first payment are written in a single transaction; once a payment exists, the order is locked.
  • Every price and stock change is logged, so each product has a history.
  • Access is checked per shop subscription, and API errors come back in English or Farsi depending on the shop’s language.

Exercise dataset, in Farsi

2026 · Python · LLM translation pipeline · JSON

An open dataset of 1,324 gym exercises — animations, target muscles, equipment — translated into Farsi, so Persian fitness apps have real data to start from. It’s a fork of hasaneyldrm/exercises-dataset; the Farsi layer is mine.

  • Every exercise got a Farsi name, full instructions and step-by-step instructions.
  • A Python script sends exercises to an LLM five at a time with a strict JSON-only prompt, waits longer after each failure, and saves progress after every batch — a dropped connection costs one batch, not the whole run.
  • Before the full run I benchmarked a few models for speed and translation quality.
  • The included browser shows the whole library in Farsi, right to left.

CommitScope

2026 · React · TypeScript · GitHub REST & GraphQL

Type in any GitHub username and get its story: contribution timeline, heatmap, languages, and a searchable list of repositories.

  • Works without signing in, using the public REST and Events APIs (about the last 90 days).
  • Add a personal access token and it switches to GraphQL for full history. GitHub caps a contributions query at one year, so it asks year by year and stitches the results together. The token never leaves your browser.
  • Responses are cached in localStorage for an hour, so revisits don’t burn the API rate limit.
